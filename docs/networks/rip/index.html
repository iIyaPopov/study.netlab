    🧰 Лабораторная работа

    Ознакомиться перед выполнением любой лабораторной работы (список раскрывается)
    • Вместо ❔ или x нужно подставить свой номер по журналу
    • Выполнять задание без "отмашки" не стоит ⛔, т.к. задание здесь может существовать более актуальная версия
    • У каждой работы есть срок сдачи 📅, который озвучивается на занятии, после которого работа не может быть защищена на максимальный балл 📉
    • Дополнительные задания 📚 не являются обязательными, но по результатам сдачи лабораторной работы может быть выдано одно или несколько из них. Также дополнительное задание может быть сформулировано устно
    • Для каждой лабораторной работы должен быть отчет 📝 с описанием выполнения ваших действий, оформление должно соответствовать требованиям (см. на сайте учебного заведения)
    • Нужно уметь ответить на вопросы ❓ по теме, контрольные вопросы и другие связанные вопросы
    • Примеры могут быть выполнены по желанию, а также выданы в качестве дополнительного задания с изменениями или без в случае неуспешной 😢 защиты основной работы
    • Иногда в работах встречаются задания по IPv4 и IPv6 одновременно 🔗. Это считается как одна работа. Допускается сдача работы только с IPv4 или только с IPv6, но максимальный балл в таком случае получить невозможно

    🎯 Цель работы: получить навыки навыки настройки дистанционно-векторных протоколов внутренней маршрутизации на примере RIP и RIPng.

    🌐 Схема

    ✔️ Условия

    1. Никаких статических маршрутов, кроме маршрута по умолчанию на R4.
    2. На R4 создать маршрут по умолчанию в сторону сети "Internet" на любой адрес из этой сети.

    3. Объявить маршрут по умолчанию на R4 с помощью RIP.

      Проверить, что "пинг" с других устройств на несуществующий адрес идет в сторону "Internet".

    4. Все маршрутизаторы должны знать обо всех сетях на схеме.

    5. При удалении каналов между маршрутизаторами доступ между устройствами должен оставаться (не мгновенное, т.к. RIP должен сойтись), где есть физическая возможность передачи данных.

    📚 Дополнительные задания

    1. Повторить основное задание, но использовать RIPng вместо RIPv2. Локальные IPv6-адреса у всех маршрутизаторов - FE80::x. Глобальный IPv6-адрес вычислить как 2001::{IPv4-адрес}/64 (. в IPv4-адресе заменить на :).

      Например, если у R1 на одном из интерфейсов настроен IPv4-адрес - 10.0.1.1/24, тогда IPv6-адрес на том же интерфейсе задать как - 2001::10:0:1:1/64.

    🤔 Контрольные вопросы

    1. Как определяют маршрутизаторы путь для пакетов при "трассировке" от PC1 до PC2?
    2. Что такое "отравление" маршрута?
    3. Какая административная дистанция у RIP?
    4. Что такое метрика и какое ее максимальное значение?
    5. Будут ли при эхо-запросе на адрес 10.x.5.100 (или любой другой, не являющийся адресом “Internet” и R4) в Wireshark отображаться ARP-запросы и ARP-ответы?
    6. Куда пойдет "пинг" на несуществующий адрес на схеме при удалении/отключении R4?
    7. Что изменится, если дополнительно к сети "Internet" подключить R6 и включить на нем распространение маршрута по умолчанию?
    8. На что влияет автосуммирование маршрутов? "Выгодно" ли использовать это на схеме?
    9. Для чего используется адрес 224.0.0.9?
    10. Сколько маршрутов на указанном маршрутизаторе, полученных указанным способом?
